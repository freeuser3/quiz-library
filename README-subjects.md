# subjects.json — справка по конфигу

Пример конфига с тремя предметами:

```json
{
  "География": {
    "book": "География. 9 класс",
    "digest": "digests/geografia.json",
    "paragraph_patterns": ["параграф", "параграфа", "§"]
  },
  "ОБЗР": {
    "book": "Основы безопасности и защиты Родины",
    "digest": "digests/obzr.json",
    "paragraph_patterns": ["тема", "темы", "модуль", "модули", "параграф", "параграфа", "§"],
    "match_paragraphs": false,
    "search_threshold": 0.2,
    "search_gap": 1.3,
    "search_llm_min": 0.25
  }
}
```

Поля:

| Поле | По умолчанию | Смысл |
|------|-------------|-------|
| `book` | — | Название учебника (для отладки/логов) |
| `digest` | — | Путь к выжимке `digests/*.json` |
| `paragraph_patterns` | — | Паттерны поиска номера параграфа (длинные первыми: «параграфа» раньше «параграф») |
| `match_paragraphs` | `true` | Обычный учебник с нумерованными параграфами; `false` — темы-модули без сквозной нумерации (ОБЗР) |
| `search_threshold` | `0.45` | Минимальный балл нечёткого совпадения по названию темы (ОБЗР: `0.2`) |
| `search_gap` | `1.3` | Если `top / second >= gap` → однозначный выбор, арбитраж не нужен |
| `search_llm_min` | `0.25` | Ниже — даже первый кандидат слаб, близких нет к лучшему |
| `search_llm_min`/gap при `ambiguous` | — | Запускается LLM-арбитраж (`choose_paragraph`) |

Title-поиск (`match_paragraphs: false`): текст нормализуется (снимаются «Модуль N. Тема M.»
в начале, пунктуация), слова сводятся к префикс-классам из 4 букв (ё→е) — так
склеиваются словоформы и OCR-искажения («безопасность/безорасного»). Балл темы —
доля токенов запроса, найденных в заголовке: `|query ∩ title| / |query|`.

`paragraph_patterns` для ОБЗР учитывают формулировки «тема N» из домашних заданий;
`match_paragraphs: false` включает title-поиск: ключи тем вида `"5.3"` (модуль.тема),
числовой каскад ищет единственный ключ `«*.N»`, иначе сверяет название.
