# Выбор LLM-модели для генерации вопросов (research report)

Дата: 2026-09-24 · Автор: opencode (по запросу пользователя)
Контекст: quiz-library генерирует один голосовой вопрос по параграфу учебника
(~5–6 кБ текста параграфа в промпте, ответ ~100–200 символов). Окно ответа Алисы —
4.5 с, поэтому приоритет — **низкая латентность**, без reasoning/thinking.

## 1. Каталог DS Lab (POST /v1/models)

В каталоге ~180 моделей: LLM, vision, audio/TTS, embedding, rerank, video/image/OCR.
Для задачи годятся только текстовые LLM, принимающие **Chat Completions**
(наш клиент llm.py использует `/v1/chat/completions`) и умеющие работать **без
режима рассуждений**.

## 2. Отсев по критериям

| Модель | Input ₽/1M | Output ₽/1M | Вердикт |
|---|---|---|---|
| deepseek-v4.1-flash (была в .env) | 30₽ | 120₽ | reasoning по умолчанию; замер 14.5 с — не вписывается в 4.5 с |
| deepseek-v4-flash | 9₽ | 18₽ | есть non-think, но замер 5.8 с — на грани |
| glm-4.7-flash | 8₽ | 44₽ | thinking опционален; замер 2.6 с — хорошо |
| **gpt-4.1-nano** | **11₽** | **44₽** | **без reasoning; замер 2.0 с — лучше всех** |
| glm-5.3-flash | 7.5₽ | 25₽ | thinking только enabled → отсев по латентности |
| gpt-5.6-luna / gpt-6-luna | 20–20₽ | 120–75₽ | нативный Responses API, Chat Completions «не рекомендуется» |
| mimo-v2.6-flash | 14₽ | 28₽ | только Responses API |
| gemini-3.x-flash / flash-lite | 30–150₽ | 250–750₽ | «мышление не отключается» + дорого |

## 4. Оценка стоимости

Промпт вопроса ≈ 4–5 K входных токенов + ~100 токенов на выход. Стоимость:
gpt-4.1-nano ≈ 0.06₽ за вопрос; glm-4.7-flash ≈ 0.04₽. Для объёмов навыка (единицы
вопросов в день) разница несущественна — доминирует латентность.

## 5. Рекомендация

**LLM_MODEL = `gpt-4.1-nano`** (основная):
- 2.0 с — единственный кандидат с запасом под окно 4.5 с (с учётом сетевых вариаций);
- без reasoning, Chat Completions, совместим с клиентом как есть;
- качество вопроса по §6 — нейтральная, естественная формулировка.

**Запасные:** `glm-4.7-flash` (дешевле, качество хорошее, но стиль разговорный —
нужна донастройка SYSTEM_PROMPT под строго нейтральную формулировку); `deepseek-v4-flash`
(5.8 с — не помещается в 4.5 с, резерв на случай проблем с gpt-4.1-nano).

## 6. Изменения

- `.env` (gitignored, локальная конфигурация навыка): `LLM_MODEL=deepseek-v4.1-flash`
  → `LLM_MODEL=gpt-4.1-nano`.
- Код библиотеки не менялся: эмпирически `thinking: {enabled: false}` в payload
  принимается всеми тремя кандидатами через шлюз DS Lab.

## 7. Оговорки

- Замеры — по одному прогону на модель (но на идентичном промпте и в один заход);
  для статистической уверенности нужен повторный прогон (bench не писался по решению
  пользователя).
- Финальный выбор пользователь подтверждает при проверке навыка; смена модели —
  правка одной строки `LLM_MODEL`.
